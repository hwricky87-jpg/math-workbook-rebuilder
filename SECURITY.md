# Security Policy

## Supported version

Security fixes are made for the latest published release. Update to the latest release before reporting a problem that may already be fixed.

## Report privately

Do not open a public issue for a vulnerability. Use [GitHub private vulnerability reporting](https://github.com/hwricky87-jpg/math-workbook-rebuilder/security/advisories/new) so repository details and a proposed fix can be discussed without public disclosure.

Never attach workbook photographs, student names, school information, generated worksheets, QA images, PDFs, credentials, or unredacted local paths. Reproduce the problem with synthetic data and remove metadata before uploading any permitted artifact.

Include the affected release, operating system, Python and Node.js versions, a minimal synthetic reproduction, and the security impact. Reports will be reviewed as availability permits; no response or resolution deadline is guaranteed.
