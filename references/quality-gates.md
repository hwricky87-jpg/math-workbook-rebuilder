# 품질 게이트

## 하드 게이트

하나라도 실패하면 최종 PDF를 전달하지 않는다.

- 문제 문장, 숫자, 단위, 보기, 기호가 원본과 일치한다.
- 문제에서 요구하는 점·선·면·내부선·경로가 모두 있다.
- 도형 위상과 면 인접 관계가 맞다.
- 좌표 추적 도형의 모든 명시적 점에 원본 픽셀 랜드마크가 있으며, 최대 정규화 오차가 manifest 허용값 이하이고 절대 상한 `0.04` 이하이다.
- 실선·점선·강조선의 역할이 맞다.
- 라벨과 치수가 대상 요소에 정확히 붙어 있다.
- 손글씨, 정답, 빨간 채점, 화면 UI가 학생용 자료에 없다.
- SVG가 잘리지 않고 최신 원본에서 렌더되었다.
- 전개도와 각기둥 불변식 검사가 통과한다.
- 문제 풀이 또는 독립적인 수학 검산이 재구성 그림과 모순되지 않는다.
- 각 문제에 원본·재작도·겹침 비교 산출물과 JSON 비교 보고서가 있고 최신 렌더를 확인했다.
- 비교 보고서의 원본 크롭·SVG·비교 이미지 해시가 현재 파일과 일치한다. 수동 불리언만 참인 비교는 인정하지 않는다.
- `source_comparison`의 모든 필수 판정이 참이며 비교 산출물 경로가 기록되어 있다.
- 모든 PDF 페이지를 렌더해 실제 눈으로 확인했다.
- 최종 PDF의 각 문제를 원본 문제 크롭과 다시 대조했다.
- 최종 대조 기록 `delivery.json`이 `scripts/validate_delivery.py`를 통과했다.

## 원본 비교 게이트

비교표에서 다음 순서로 본다.

1. 꼭짓점 개수와 연결 관계
2. 내부 선 하나하나의 존재
3. 보이는 선과 숨은 선
4. 라벨·치수의 대상과 방향
5. 전체 실루엣과 원근 비율
6. 글자 겹침, 잘림, 과도한 여백

좌표 추적 도형은 위 순서 전에 원본 픽셀 랜드마크 검사를 수행한다. 최대 정규화 오차가 임계값을 넘으면 비교표가 보기 좋아도 즉시 실패다.

원본의 흐릿함까지 복제할 필요는 없지만, 원본에서 읽을 수 있는 구조적 정보는 전부 보존한다.

## 회귀 검사

승인된 사례마다 원본 크롭, manifest, SVG, QA 결과를 보관한다. 새 버전은 최소한 다음을 자동 검사한다.

- SVG/manifest 생성 성공
- required label과 required segment 존재
- trace source landmark 완전성, 실제 크롭 크기 일치, 정규화 오차 상한
- 전개도 면·접는선·외곽선 수
- 연결성 및 세 면 이상 공유 변 없음
- viewBox 대비 잉크 여백
- PDF 페이지 수와 페이지 경계
- 벡터가 필요한 문서에 우발적인 래스터 이미지가 들어가지 않았는지
- 비교 보고서 해시가 현재 원본 크롭과 SVG를 가리키는지

자동 검사는 시각 검사를 대신하지 않는다. 자동 검사 통과 후 최신 PNG 또는 PDF 렌더를 확인해야 한다.

## 품질 기준선

이 스킬에서 말하는 최소 기준선은 Claude 결과물에서 확인된 다음 장점을 포함한다.

- 점과 선을 좌표로 명시한다.
- 각기둥의 면과 가시성을 일관된 함수로 만든다.
- 전개도 접는선을 면 공유 관계로 계산한다.
- 이미지 판독은 확대본과 수치 프로브를 함께 사용한다.
- 문제를 풀어 판독 결과를 검산한다.

여기에 Codex 공동 작업에서 발전시킨 다음 검증 방식을 추가한다.

- 원본 옆 비교표와 모든 페이지 렌더 검수
- 문제별 manifest와 재현 가능한 산출물
- 오류 사례의 회귀 시험화
- 선·라벨·잘림을 자동으로 차단하는 하드 게이트

자세한 결합 방식과 최종 원본 대조 절차는 [methods.md](methods.md)를 따른다.
