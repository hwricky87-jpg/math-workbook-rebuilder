# 품질 게이트

## 하드 게이트

하나라도 실패하면 최종 PDF를 전달하지 않는다.

- 문제 문장, 숫자, 단위, 보기, 기호가 원본과 일치한다.
- 문제에서 요구하는 점·선·면·내부선·경로가 모두 있다.
- 도형 위상과 면 인접 관계가 맞다.
- 좌표 추적 도형의 모든 명시적 점에 원본 픽셀 랜드마크가 있으며, 최대 정규화 오차가 manifest 허용값 이하이고 절대 상한 `0.04` 이하이다.
- 좌표와 선분 목록이 현재 원본 해시를 가진 별도 관측 JSON에서 왔고 manifest와 일대일로 일치한다.
- 같은 두 끝점 사이의 중복 선분이나 실선·점선 충돌이 없다.
- 실선·점선·강조선의 역할이 맞다.
- 라벨과 치수가 대상 요소에 정확히 붙어 있다.
- 손글씨, 정답, 빨간 채점, 화면 UI가 학생용 자료에 없다.
- SVG가 잘리지 않고 최신 원본에서 렌더되었다.
- 전개도와 각기둥 불변식 검사가 통과한다.
- `verification_evidence`가 재구성 값 바깥의 근거를 기록한다. 같은 판독으로 계산한 깔끔한 답은 기대값으로 인정하지 않는다.
- 외부 답은 근거 산출물과 해시가 현재 파일과 일치하고, 손글씨는 신뢰성이 별도로 확인되었다.
- 다중간선 그래프의 모든 degree/cut 프로브가 하나의 안정값으로 통과하고 현재 원본 해시를 가리킨다.
- 프로브의 원시 표본에서 안정값을 다시 계산한 결과가 보고된 `ok`·`stable_count`와 같다.
- 다중간선의 실측 차수, 간선에서 계산한 차수, 차수 합 `2|E|`, 다중도와 실제 SVG 가닥 수가 모두 일치한다.
- 문제 풀이 또는 독립적인 수학 검산이 재구성 그림과 모순되지 않는다. 깔끔한 계산 결과만으로 통과시키지 않는다.
- 각 문제에 원본·재작도·겹침 비교 산출물과 JSON 비교 보고서가 있고 최신 렌더를 확인했다.
- 비교 보고서의 원본 크롭·SVG·비교 이미지 해시가 현재 파일과 일치한다. 수동 불리언만 참인 비교는 인정하지 않는다.
- 비교 보고서의 재작도 잉크가 허용 거리 안에서 원본 잉크와 충분히 겹치고, 관측 꼭짓점 영역 안에 재작도로 설명되지 않는 긴 원본 직선 잔차가 없으며, 모든 선언된 실선·강조선이 방향 정렬된 좁은 띠에서 원본의 지속적인 중심-측면 대비를 보이고, 항목별 수동 판정은 별도의 해시된 review JSON과 일치한다. 평평한 음영이나 다른 선분의 국소 임계값이 해당 선분의 지지로 계산되면 실패다.
- `source_comparison`의 모든 필수 판정이 참이며 비교 산출물 경로가 기록되어 있다.
- 모든 PDF 페이지를 렌더해 실제 눈으로 확인했다.
- 최종 PDF의 각 문제를 원본 문제 크롭과 다시 대조했다.
- 최종 대조 기록 `delivery.json`이 `scripts/validate_delivery.py`를 통과했다.

## 원본 비교 게이트

비교표에서 다음 순서로 본다.

1. 꼭짓점 개수와 연결 관계
2. 내부 선 하나하나의 존재
3. 보이는 선과 숨은 선
4. 라벨·치수의 대상과 방향
5. 전체 실루엣과 원근 비율
6. 글자 겹침, 잘림, 과도한 여백

좌표 추적 도형은 위 순서 전에 원본 픽셀 랜드마크 검사를 수행한다. 최대 정규화 오차가 임계값을 넘으면 비교표가 보기 좋아도 즉시 실패다.

원본의 흐릿함까지 복제할 필요는 없지만, 원본에서 읽을 수 있는 구조적 정보는 전부 보존한다.

## 회귀 검사

승인된 사례마다 원본 크롭, manifest, SVG, QA 결과를 보관한다. 새 버전은 최소한 다음을 자동 검사한다.

- SVG/manifest 생성 성공
- required label과 required segment 존재
- trace source landmark 완전성, 실제 크롭 크기 일치, 정규화 오차 상한
- 전개도 면·접는선·외곽선 수
- 연결성 및 세 면 이상 공유 변 없음
- viewBox 대비 잉크 여백
- PDF 페이지 수와 페이지 경계
- 벡터가 필요한 문서에 우발적인 래스터 이미지가 들어가지 않았는지
- 비교 보고서 해시가 현재 원본 크롭과 SVG를 가리키는지
- 자기참조 expectation 종류가 거부되는지
- 자기참조 trace 관측, 중복 실선·점선, 원본에서 이탈한 재작도 잉크, 재작도에서 누락된 긴 원본 선, 주변 꺾은선에 가까워 전체 평균만 통과한 가짜 현, 일괄 승인 review 누락이 거부되는지
- 다중간선에서 차수 누락, 간선 과소계수, 중복 SVG 가닥, 오래된 프로브 보고서가 거부되는지
- SVG `<defs>` 안의 pattern 요소가 실제 잉크 bbox로 잘못 계산되지 않는지
- 기본 인쇄 스타일의 일반선이 2배 래스터에서 충분한 실제 두께를 가지며 한글·라틴 꼭짓점 기호가 실제 잉크로 렌더되는지
- 전처리 표시 크기가 고정 배율이 아니라 긴 변 상한에 맞게 적응하고, 명시적 `--scale` 재정의는 그대로 보존되는지
- 공유 비교 증거를 사용한 결과가 독립 계산 결과와 동일하고, 선분 허용 반경이 원본 획 굵기로 제한되는지
- 원본 거리장이 비교 실행당 한 번만 계산되고, 내용 해시가 같은 SVG 래스터만 캐시에 적중하며, 캐시 사용 여부와 단계별 시간이 보고되는지
- 방향 정렬 국소 띠가 흐린 실제 선은 승인하면서 평평한 음영을 가짜 선으로 승인하지 않는지
- 좌표 격자가 crop-local native pixel 눈금을 표시하고, 개별 판독본은 고해상도를 유지하면서 전체 inspection sheet만 크기 상한을 지키는지

자동 검사는 시각 검사를 대신하지 않는다. 자동 검사 통과 후 최신 PNG 또는 PDF 렌더를 확인해야 한다.

## 품질 기준선

이 스킬의 최소 기준선은 실제 작업과 회귀 시험에서 효과가 확인된 다음 재작도 방식을 포함한다.

- 점과 선을 좌표로 명시한다.
- 각기둥의 면과 가시성을 일관된 함수로 만든다.
- 전개도 접는선을 면 공유 관계로 계산한다.
- 이미지 판독은 확대본과 수치 프로브를 함께 사용한다.
- 문제를 풀어 판독 결과를 검산한다.

여기에 다음 자동 검증 방식을 결합한다.

- 원본 옆 비교표와 모든 페이지 렌더 검수
- 문제별 manifest와 재현 가능한 산출물
- 오류 사례의 회귀 시험화
- 선·라벨·잘림을 자동으로 차단하는 하드 게이트
- 검증 기대값의 출처 기록과 자기참조 차단
- 다중간선의 원형 차수·수직 절단·그린 가닥 수 교차검증

자세한 결합 방식과 최종 원본 대조 절차는 [methods.md](methods.md)를 따른다.
