# 결합 재작도·검증 방법

이 스킬은 한 모델의 즉흥적인 그림 생성에 의존하지 않는다. 실제 작업에서 효과가 확인된 재작도 방식과 자동 검증·회귀 시험을 하나의 재현 가능한 절차로 결합한다.

## 유지할 가치가 검증된 재작도 방식

- 사진의 2차원 투영을 좌표로 직접 기록한다.
- 규칙적인 각기둥은 꼭짓점과 면 가시성을 파라미터 함수로 생성한다.
- 전개도는 선을 손으로 분류하지 않고, 면들이 공유하는 변을 세어 접는선과 외곽선을 결정한다.
- 확대·대비·이진화 이미지와 수치 프로브를 함께 사용해 점선, 내부선, 인쇄선과 손글씨를 구분한다.
- 확대본·국소대비본·선명화본·적응형 이진화본은 판독 보조본으로만 사용한다. 선의 존재와 좌표는 원본 native crop에서 다시 확인한다.
- 재구성한 수치로 문제를 직접 풀어 판독 결과의 개연성을 확인한다.
- 최종 조판 전에 도형만 모은 미리보기를 확인한다.

## 자동화된 증거와 회귀 검증

- 문제별 manifest에 원본 위치, 전사문, 도형 구조, 판정 근거와 검사 상태를 남긴다.
- 각 도형마다 SOURCE / REDRAW / OVERLAY 비교 이미지를 만든다.
- 좌표 추적 도형은 원본 픽셀 랜드마크와 SVG 좌표의 정규화 오차를 계산하고, 수치 검사가 통과한 뒤에만 수동 판정을 기록한다.
- 원본 관측 JSON은 manifest보다 먼저 만들고 별도 해시로 고정한다. 관측 점·선분을 manifest에서 다시 생성한 파일은 독립 증거가 아니다.
- 재작도→원본 잉크 근접률을 계산해 좌표 몇 점만 맞고 중간 선이 휘거나 새로 생기는 경우를 거부한다.
- 원본→재작도 잔차도 별도로 계산한다. 관측 꼭짓점 볼록껍질 안에서 재작도로 설명되지 않는 긴 직선 잔차가 남으면, 목록에 이름을 붙이지 못한 선이라도 누락으로 거부한다.
- 각 실선·강조선의 원본 좌표 중심선을 좁은 허용 반경으로 별도 표본화한다. 전체 그림 평균이 좋아도 한 선분의 지지율이 낮거나 연속 미지지 구간이 길면 가짜 선으로 거부한다.
- 원본과 새 그림의 위상, 내부선, 실선·점선, 라벨, 치수, 비례를 항목별로 확인한다.
- 브라우저와 PDF 렌더러 사이의 SVG 차이를 실제 렌더로 검사한다.
- SVG viewBox, 글자와 곡선의 잉크 범위, PDF 페이지 경계를 자동 검사한다.
- 누락선과 잘림이 실제로 거부되는 음성 시험과 승인 사례 회귀 시험을 실행한다.
- 결과물을 내기 직전에 원본 문제 크롭과 최종 PDF를 다시 대조한다.

## 검증 근거의 독립성

재구성한 값으로 계산한 결과를 같은 값의 기대값으로 사용하면 오독을 검출할 수 없다. 깔끔한 정수나 흔한 교재 수치가 나왔다는 사실도 통과 근거가 아니라 개연성 신호다.

모든 실제 원본 manifest에는 `verification_evidence`를 기록한다.

- `external-answer`: 인쇄 답, 해설지, 신뢰성이 확인된 손글씨처럼 재구성 바깥에서 온 값. 근거 파일과 해시를 남긴다.
- `independent-invariant`: 전개도의 면·접는선·외곽선 수처럼 판독한 개별 선과 다른 구조적 불변량.
- `independent-measurement`: 다중간선의 중점 절단 수와 꼭짓점 원형 차수처럼 서로 다른 위치·방식으로 얻은 측정.
- `user-confirmation`: 사용자가 원본 대조표로 확인한 경우. 확인에 사용한 최신 비교 산출물과 해시를 남긴다.

손글씨 답은 학생이 틀렸을 수 있으므로 그 자체로 절대 기준이 아니다. 채점 표시, 해설, 독립 계산 등으로 신뢰성이 확보된 경우에만 `external-answer`로 쓴다.

다중간선 그래프는 같은 사진을 사용하므로 차수 측정 하나만으로 완전한 독립 증거가 되지는 않는다. 다음을 함께 만족해야 한다.

1. 각 꼭짓점의 여러 반지름 원에서 가닥 수가 연속 표본에 걸쳐 하나의 값으로 안정된다.
2. 각 간선 다발의 중점 수직 절단에서도 여러 절단 길이에 걸쳐 개수가 안정된다.
3. 간선 다발에서 계산한 모든 꼭짓점 차수가 원형 측정 차수와 일치한다.
4. 차수 합이 전체 간선 수의 두 배와 같다.
5. manifest의 `drawn_elements` 개수가 다중도와 같고 실제 SVG 요소 이름과 일치한다.
6. 모든 프로브 JSON의 원본 해시가 현재 크롭과 같다.

## 필수 원본 대조 순서

각 문제마다 다음 순서를 모두 수행한다.

1. 원본 문제 크롭과 전사문을 문장·숫자·단위·기호 단위로 대조한다.
2. 원본 도형과 최신 SVG 렌더를 나란히 놓고 꼭짓점과 연결 관계부터 본다.
3. `trace_evidence`의 모든 원본 꼭짓점이 존재하는지 확인하고 정규화 최대 오차가 허용값 이하인지 검사한다. 이 단계가 실패하면 이후 수동 판정을 진행하지 않는다.
4. 반투명 겹침 이미지로 전체 비례, 누락선, 위치 이탈을 확인한다. 두 이미지가 독립적으로 보기 좋게 맞춰졌다는 이유만으로 투영 일치를 판정하지 않는다.
5. 사용자 피드백이나 문제 문구에 나온 선부터 찾지 말고, 도형의 각 면을 한 방향으로 훑으며 원본의 모든 선을 관측 목록과 일대일 대조한다. 특히 면 내부 대각선을 별도 항목으로 센다.
   Hough 잔차나 확대본에서 보이는 짧은 조각은 양 끝점을 확정하지 않는다. 후보 양 끝점 사이 전체 중심선이 원본에서 연속 지지를 받을 때만 하나의 선분으로 선언한다.
6. 문제에서 언급한 점·선·면·경로가 새 그림에 실제로 존재하는지 확인한다.
7. 실선·점선·강조선과 치수 보조선의 역할을 확인한다.
8. 비교 결과, 비교 이미지·수치 보고서·항목별 수동 review JSON 경로를 manifest의 `source_comparison`에 기록한다. 세 산출물의 원본·SVG 해시가 현재 파일과 일치해야 한다.
9. 최종 PDF 렌더 뒤 원본 크롭과 다시 대조한다. SVG 단계에서 맞았더라도 PDF에서 잘리거나 축소될 수 있기 때문이다.

비교를 수행하지 않았거나 비교 산출물이 없으면 완료로 취급하지 않는다.
